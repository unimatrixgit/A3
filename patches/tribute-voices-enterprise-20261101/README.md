# Odo and Picard tribute patch (prepared)

Dedicated to René Auberjonois and Patrick Stewart.

Picard uses the original installed Armada II recordings for selection, movement, attack, repair and other commands. The existing Federation Enterprise-D/E heroes use a shared explicit Picard event set. No generated actor imitation is included.

The allied USS Enterprise-E is added to Bajor’s Shakaar Command Yard (slot 9), with its own Bajoran unit definition, existing Enterprise-E model and build/group art. It follows Kira’s prerequisites; its Corbomite Reflector uses Bajoran research. Heroes remain buildable only.

Odo recordings are still pending: no Odo command pack was found locally or in the online searches. TrekCore has original Harbinger performances, including an Odo-only conversation, but labels its captures for exclusive TrekCore use. Those captures have not been bundled. Odo’s current live voice mapping is unchanged.
