# Battle Array defence patch

Prepared, not applied. All eleven array definitions gain array-only gun range 600 to 750, aligned target acquisition, explicit native attack permissions, passive cloak detection, and two faction light craft. Existing abilities, damage, reload, prices, crew and light-craft research remain unchanged. Original Borg-only transwarp is preserved.

The Federation uses Venture + Defiant; Klingons NuQ'Duj + Bird-of-Prey; Dominion scout + its existing outpost attack-fighter entry. Ferengi use Bronta fighter as their light reconnaissance craft and Goront frigate. Other factions use their native scout and small destroyer, raider or fighter.

The native 15000 sensor range is reduced to 750 to avoid holding an unreachable primary target. In-game auto-fire and inherited alert state still require testing. No unverified forced-red-alert commands are added.
