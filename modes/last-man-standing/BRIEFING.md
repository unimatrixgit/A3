# Last Man Standing

Subspace relays across the sector are falling silent. Outlying fleets have scattered, and the surviving powers are preparing emergency regrouping plans. A lost shipyard need not mean the end of a civilization.

Each computer-controlled faction has one reserve task force: a faction hero, nine escorts and a constructor. When its last constructor is lost while a structure still survives, that force can redeploy to a different, verified safe resource site. Emergency supplies fund the first stage of rebuilding.

One rescue is available per AI per match. Saving and loading must not restore a spent rescue. Human players receive no rescue. If no suitable location is safe, deployment waits; it cannot revive an already eliminated faction.

## Development state

The rule controller is implemented for offline testing. The mission adapter, validated relocation sites, loader compatibility and gameplay test remain required. This file is not a claim that a playable mode is installed.
